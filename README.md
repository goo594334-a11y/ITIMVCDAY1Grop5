# ITI MVC Group 5

A learning project built with **ASP.NET Core MVC** and **Entity Framework Core** as part of ITI practice.

## Tech Stack

- C# and .NET 10
- ASP.NET Core MVC
- Entity Framework Core 10
- Microsoft SQL Server
- Razor Views
- Data Annotations and custom validation

## Project Areas

The current source structure includes:

- **Courses** — course-related MVC functionality.
- **Instructors** — instructor management and related views.
- **Products** — product-related models and controller functionality.
- **ViewModels** — models prepared for transferring data between controllers and views.
- **Validation** — validation-related components.
- **Data** — application data context and migrations.

## Getting Started

1. Clone the repository.
2. Open `ITIMVCDAY1Grop5.slnx` with a compatible .NET IDE.
3. Review the connection string in your local configuration.
4. Restore dependencies and build the solution.
5. Apply database migrations only after confirming the intended local database configuration.

> **Note:** Do not commit real database credentials or other secrets. Configure your own local connection string before running the application.

## Purpose

This repository demonstrates practical ASP.NET Core MVC concepts, including controllers, models, views, ViewModels, Entity Framework Core, and validation.
